# Imagens extraídas da página pública da Kazamais

As imagens estão separadas por finalidade para serem copiadas para um projeto React/Vite:

- `images/banners`: imagens do hero da página;
- `images/products`: imagens dos produtos exibidos no catálogo;
- `images/brands`: logo da Kazamais e logos de fabricantes;
- `images/store`: imagem da fachada.

Os arquivos foram baixados mantendo uma cópia local para evitar que o projeto dependa dos links externos do WordPress.

Verifique autorização da empresa antes de publicar ou utilizar comercialmente logos, fotografias e textos.
